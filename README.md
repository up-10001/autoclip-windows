# 自动剪辑工具 AutoClip（Windows RTX 3060 12G 专用版）

面向中老年短视频观众的英文视频全自动剪辑工具：本地高速英文语音识别 + DeepSeek 智能翻译与单行语义断句 + 升级版羽化隐形蒙版去重 + NVENC 显卡硬件加速批量导出。

## 核心功能
- **DeepSeek API 开箱即用**：界面顶部内置 DeepSeek 接口栏，粘贴您的 API Key 点击“测试连接”即可自动保存使用。
- **大批量导入与硬件自适应并发**：支持一次导入 10 个、20 个甚至整个文件夹的视频；程序自动检测显卡（RTX 3060 12G 自动开启 2 路 NVENC 并行压制 + 4 路 DeepSeek 并行翻译 + GPU 共享锁防爆显存），低配电脑自动退回顺序剪辑。
- **严格单行均匀字幕**：精准复刻您的亮黄色 `#F4EA46` + 粗黑描边阴影 + 单行居中排版（`84%` 高度，紧贴原英文字幕下方），绝不折成两行、不断成半截句。
- **升级版羽化隐形蒙版 & 综合去重**：将原顶部 30% 硬切蒙版升级为平滑余弦羽化蒙版（彻底消除人物脸部横缝），叠加肉眼无感的微缩放/微调色/元数据重写/音频响度均衡。
- **灵活输出**：界面一键切换输出 **MP4** 或 **MOV**，支持实时安全区预览与可选“压制前暂停校对字幕”。

## 如何在 Windows 上生成可直接双击的 EXE

> 说明：由于当前开发环境为 macOS，无法直接跨平台生成带 Windows CUDA 依赖的原生 `.exe`，项目已提供以下两种一键生成 Windows EXE 的方式：

### 方式一：在 Windows 电脑上双击一键打包（最简单，约 3 分钟）
1. 将整个 `自动剪辑` 文件夹拷贝到您的 Windows 电脑。
2. 确保已安装 Python 3.10 或 3.11（安装时勾选 `Add Python to PATH`）。
3. 直接双击运行 **`一键打包EXE.bat`**。
4. 等待完成，自动弹出 `dist\AutoClip\` 文件夹，里面即包含可直接双击运行的 **`AutoClip.exe`**（已内置 FFmpeg 与 CUDA 加速库，拷贝整个 `AutoClip` 文件夹到任意 Windows 电脑都能直接双击用）。

### 方式二：零安装云端自动生成 EXE（GitHub Actions）
1. 将本文件夹上传到您的 GitHub 仓库。
2. 打开仓库的 **Actions → Build Windows EXE (RTX 3060) → Run workflow**。
3. 几分钟后直接下载产物 `AutoClip-Windows-RTX3060.zip`，解压双击 `AutoClip.exe` 即可使用。

## 首次使用步骤
1. 双击打开 `AutoClip.exe`。
2. 在顶部填入您的 **DeepSeek API Key**，点击 **「测试连接」**。
3. 点击 **「＋ 批量导入视频」** 或 **「📁 导入文件夹」**，一次选中 10–20 个素材。
4. 右侧选择输出格式（MP4 或 MOV），可点 **「效果预览」** 检查字幕与平台安全区红线。
5. 点击 **「▶ 开始批量剪辑」**（首次运行会自动从国内镜像下载 `large-v3-turbo` 语音模型到 `models/` 目录，之后全程本地秒开）。
